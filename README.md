# 🌍 Wanderlust - Trip Booking Web Application

Plan less, travel more. Discover curated tour packages and enjoy seamless trip booking anytime, anywhere.

🔗 **Live Site:** [https://vercel.app](https://vercel.app)  
💻 **Client Repo:** [Wonderlust-client](https://github.com)  
⚙️ **Server Repo:** [Wonderlust-server](https://github.com)  

## ✨ Features
- Search destinations by location, date, budget, and guests
- Explore curated travel packages and add new destinations
- Manage personal profile and track bookings (`My Bookings`)
- Secure user authentication and responsive design

## 🛠️ Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, Express.js, MongoDB
- **Deployment:** Vercel

## 🚀 Local Setup
```bash
git clone https://github.com.git
cd Wonderlust-client
npm install
npm run dev
```
